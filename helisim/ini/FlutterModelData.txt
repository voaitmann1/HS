Данные для МОДЕЛИ ФЛАТЕТРА

Режимы флаттера:

Учет  взаимодействия лопастей: (1- да; 0 - нет, рассмотрение флаттера изолированной лопасти)

FlutterMode_ConsiderBladesInteraction=  0

Учет  трения: (1- да, 0 - нет)

FlutterMode_ConsiderFriction=  0

Ожидаемая амплитуда (только при учете сил трения):
fiAfl= 0.5

Ожидаемая частота колебаний при флаттере (только при учете сил трения):
рfl= 6

WeightCentersDataMode= 1 


Дополнительные параметры ВЕРТОЛЕТА, необходимые для расчета  флаттера:

Жесткость на кручение системы управления:

CtrlSysRotRigidity= 25000

Тип упорного подшипника (0 - шариковый, 1 - роликовый):

LagerTypeN= 0

Радиус упорного подшипника (0 - шариковый, 1 - роликовый):

LagerR= 0.1

Коэффициент трения в упорном подшипнике:

LagerKFrict= 0.003
